# Review Document
## HTML评审文档预览
GitHub原生打开HTML文件只会展示源码，可使用下面两种方式预览网页：

1. **临时预览（htmlpreview，无需配置）**
使用前缀：**https://htmlpreview.github.io/?**  后面拼接具体html文件完整链接。
##### 例如：
拼接地址：`https://htmlpreview.github.io/?https://github.com/starsoda-qin/ReviewDocument/blob/main/12月1日版本/20261130版本.html`
> 缺点：第三方服务，稳定性有限，适合临时分享评审

2. **正式预览（GitHub Pages，推荐长期使用）**
使用域名：**https://starsoda-qin.github.io/ReviewDocument/**  后面加上html文件路径。
##### 例如：
访问地址：`https://starsoda-qin.github.io/ReviewDocument/12月1日版本/20261130版本.html`
> 优点：官方静态服务，链接稳定，图片、样式等资源加载正常
